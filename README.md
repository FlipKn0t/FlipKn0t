# Flight Check

An iOS app (and web app) that tells you whether local conditions are safe to fly **your**
drone. Pick your aircraft, and wind, temperature and altitude warnings scale to its
published limits.

It uses the same web code everywhere. [Capacitor](https://capacitorjs.com/) wraps it as a
native iOS app, and the same files also run as a home-screen web app.

## Features

- **Go / Caution / Don't fly** verdict for right now, plus each of the next 24 hours, with
  the next good flying window called out.
- **Wind vs. aircraft limit meter** shows wind and gusts against your drone's rated wind
  resistance.
- **Drone picker** covering Neo, Neo 2, Lito 1, Lito X1, Flip, Mini 4K, Mini 4 Pro, Mini 5 Pro,
  Air 3, Air 3S, Mavic 3 Pro, Mavic 4 Pro, Avata 2 and Avata 360. There's also a **Custom**
  profile for any other aircraft.
- Checks for wind, gusts, wind at 80 m, rain and snow, thunderstorms, visibility, temperature,
  fog risk, daylight, GPS (Kp index) and takeoff altitude.
- Location from GPS or by place search. Units in mph, km/h, m/s or knots, °F or °C, and miles or km.
- Dark-first design, with a light theme that follows the system setting.

## How the checks scale

`L` is the selected drone's rated max wind speed.

| Check | Go | Caution | Don't fly |
|---|---|---|---|
| Wind (10 m) | < 50% of L | 50–80% of L | ≥ 80% of L |
| Gusts | < 70% of L | 70–100% of L | ≥ L |
| Wind at 80 m | < 75% of L | 75–100% of L | ≥ L |
| Precipitation | dry, < 40% chance | ≥ 40% chance | any rain, snow or drizzle |
| Thunderstorm | | | any |
| Visibility | ≥ 5 km | 1–5 km | < 1 km |
| Temperature | inside the rated range | cold (< 5 °C) or within 5 °C of the limits | outside the rated range |
| Fog / condensation | temp − dew point ≥ 2 °C | < 2 °C | fog reported |
| Daylight | day | night | |
| GPS (Kp index) | < 5 | 5–6 | ≥ 7 |
| Takeoff elevation | | | above the drone's max takeoff altitude |

Drone limits are in [`www/drones.js`](www/drones.js). They come from the manufacturer's
published spec sheets. Two Lito 1 figures (minimum temperature and max takeoff altitude)
couldn't be confirmed, and the app says so. Thresholds are in [`www/conditions.js`](www/conditions.js).

## Run on your iPhone

You need a Mac with **Xcode** (free from the Mac App Store).

```sh
npm install
npm run ios          # syncs www/ into the iOS project and opens Xcode
```

In Xcode:

1. Select the **App** target, then **Signing & Capabilities**. Choose your **Team**. A free
   Apple ID works; sign in under Xcode → Settings → Accounts. If Xcode complains that the
   bundle identifier is taken, change it to something unique.
2. Plug in your iPhone, select it as the run destination and press **Run** (▶).
3. On the phone, go to Settings → General → VPN & Device Management and trust your developer
   certificate. On iOS 16 or later, also turn on Settings → Privacy & Security → Developer Mode.

With a free Apple ID the app stays installed for 7 days before you need to run it from Xcode
again. To install it for good, or to share it through TestFlight or the App Store, you need
the paid Apple Developer Program.

After you change anything in `www/`, run `npm run sync` (or `npm run ios`) to copy it into
the iOS project.

## Run as a web app

```sh
npm start            # serves www/ on http://localhost:8080
```

To host it: set **Settings → Pages → Source** to **GitHub Actions**. The *Deploy web app to
GitHub Pages* workflow then publishes `www/` on every push to `main`, or you can run it by hand.

## Tests

```sh
npm test
```

CI runs the tests and compiles the iOS app for the simulator on a macOS runner.

## Data sources

- [Open-Meteo](https://open-meteo.com/): forecast and place search (free, no key)
- [NOAA SWPC](https://www.swpc.noaa.gov/): planetary K-index, for GPS reliability
